# PUBG Mortar Distance Calculator

Aplicación para calcular automáticamente la distancia en metros entre un jugador y su marca en el mapa de PUBG mediante procesamiento de imagen.

## Características
- Detección de coordenadas de jugadores (1, 2, 3, 4).
- Identificación de marcadores por color (Amarillo, Azul, Rojo, Verde).
- Cálculo de distancia en metros según la escala del mapa.
